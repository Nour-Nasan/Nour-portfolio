# Nour Nasan — Personal Portfolio

A personal portfolio website created to showcase my work, technical skills, and experience as a Software Engineer and Full-Stack Developer.

The portfolio provides a simple and responsive way to explore my work, learn more about my technical background, and access my professional profiles and contact information.

## Live Portfolio

[View My Portfolio](https://nour-nasan.github.io/Nour-portfolio/)

## About the Portfolio

This website serves as my personal online portfolio and will continue to evolve as I build new projects, learn new technologies, and gain more experience in software development.

It provides a central place to present my development work while keeping the portfolio flexible and easy to update over time.

## Features

- Responsive design for desktop and mobile devices
- Personal introduction and professional profile
- Technical skills section
- Project showcase
- Project screenshots and descriptions
- Links to live demos and source code when available
- Contact section
- GitHub and LinkedIn links
- Clean and modern user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## Purpose

The purpose of this portfolio is to provide a professional online presence where recruiters, companies, and other developers can learn more about my skills and explore my work.

The website is designed to grow over time, allowing new projects, technologies, and skills to be added as my experience develops.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/Nour-Nasan/Nour-portfolio.git
```

Open the project folder and launch `index.html` in your web browser.

No additional installation or backend server is required.
